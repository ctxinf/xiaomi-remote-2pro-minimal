

## 工作流程

```
遥控器麦克风键按下
        │
        ├─► [start 事件] ──► 执行 start hook 脚本（此时还没有音频文件）
        │
   ATVV 语音流 → IMA ADPCM 解码 → 16 kHz / 16-bit PCM
        │
        ▼
   写入临时 WAV 文件：$TMPDIR/xiaomi-remote-gateway/record_<时间戳>.wav
        │
遥控器麦克风键松开
        │
        └─► [end 事件] ──► 执行 end hook 脚本，并传入该音频文件路径
```

- `start`：语音流开启时触发，`audio_file` 为 `null`。
- `end`：语音流结束**且生成了有效音频文件**时触发（过短的误触不会触发，阈值 50 ms，且其文件会被直接丢弃）。
- 当前录音文件归 `end` hook 所有：可自行转写、上传、移动或删除；当前录音在本轮清理中被保护；后续录音或重启仍可能按保留策略清理旧文件，耗时较长的 Hook 应自行复制文件或关闭清理。
