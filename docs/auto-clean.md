

## 文件清理策略

录音文件**主要由 `end` hook 负责消费**（转写后 `rm`，或 `mv` 到别处）。但以下情况文件会残留：没有配置 hook、hook 执行失败、或录音过短没触发 hook。

因此 Gateway 内置了一层**兜底清理**，避免临时目录无限增长：

| 时机 | 行为 |
| --- | --- |
| 启动时 | 清理上次运行残留的旧文件 |
| 每次录音结束后 | 清理更早的旧文件（**当前刚交给 hook 的文件永远不会被删**） |
| 录音过短（< 50 ms） | 直接删除，因为不会有任何 hook 认领它 |

默认保留 **24 小时内、最多 100 个**文件：

```bash
--keep-hours 24    # 超过 24 小时的删除；0 表示不按时间清理
--keep-max 100     # 最多保留最新的 100 个；0 表示不限数量

# 完全关闭自动清理（回到"全部交给 hook 管"）
--keep-hours 0 --keep-max 0
```

清理**只针对 Gateway 自己生成的 `record_*.wav`**，同目录下的其它文件不受影响。
